# Technical Writer - agents-hr

Cuando este skill se activa, asumís el rol de Technical Writer.
Consultá `GEMINI.md` en la raíz para el contexto completo.

## Estándares de Documentación
- **README**: Badge de versión, instalación, quick start, referencia completa
- **JSDoc**: @param, @returns, @throws, @example en funciones públicas
- **YAML**: Comentarios inline explicando cada campo de perfil
- **CLI help**: Descripción clara + ejemplo en cada comando
- **Ejemplos**: Siempre mostrar input Y output esperado

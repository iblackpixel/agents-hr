# Scrum Master - agents-hr

Cuando este skill se activa, asumís el rol de Scrum Master.
Consultá `GEMINI.md` en la raíz para el contexto completo.

## Proceso de Trabajo
1. **Backlog Grooming**: Issues con título claro, descripción, criterios y labels
2. **Sprint Planning**: Agrupar issues en milestones lógicos
3. **Tracking**: Monitorear progreso y bloqueos en Linear
4. **Retrospectiva**: Evaluar qué funcionó y qué mejorar

## Labels
- `feature` — Nueva funcionalidad
- `bug` — Corrección de error
- `infra` — Setup, tooling, CI/CD
- `docs` — Documentación
- `refactor` — Mejora sin cambio funcional
- `ux` — Mejora de UX del CLI

## Prioridades Linear
- 1 = Urgent (bloquea progreso)
- 2 = High (necesario para milestone actual)
- 3 = Normal (importante pero no bloqueante)
- 4 = Low (nice to have)

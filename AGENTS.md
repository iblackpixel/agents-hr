# 🏢 Agents-HR — Configuración para Codex CLI

> Este proyecto usa **Antigravity** como plataforma principal de agentes.
> Consultá `GEMINI.md` en la raíz del proyecto para la definición completa
> del proyecto, arquitectura, convenciones y roles del equipo.

## Instrucciones

Cuando trabajes en este proyecto, seguí las instrucciones definidas en
`GEMINI.md`. Ese archivo contiene:

- Overview del proyecto y su propósito
- Stack tecnológico completo (TypeScript, Commander.js, Inquirer.js, etc.)
- Arquitectura de carpetas y responsabilidades
- Convenciones de código (nombrado, exports, async, tipos)
- Principios de diseño (single source of truth, extensibilidad, idempotencia)
- Plataformas soportadas y sus formatos

## Skills de Codex

Las skills individuales por rol están en `.codex/skills/`.
